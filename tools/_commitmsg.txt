三、本机每周计划任务
  tools/run_local_probe.cmd + Windows 任务 clash-source-local-probe
  每周日 03:07，StartWhenAvailable（到点关机则开机补跑），失败重试 2 次
  已实测：任务拉起 -> 全量探针 -> 健康档案 -> 推回 main 全链路通
  计划任务里踩到的四个坑一并修掉：
   - .cmd 必须纯 ASCII：cmd.exe 按 OEM 码页(936)读 .cmd，UTF-8 中文注释
     会把行结构搞乱，报「xxx 不是内部或外部命令」
   - .cmd 必须 CRLF：LF-only 会让 %ERRORLEVEL% 变空，退出码永远传不出来
   - pull --rebase 必须加 --autostash：工作区有未暂存改动时 rebase 直接拒绝，
     导致「push 被拒 -> rebase -> 重试」必然二次失败，本地数据永远传不上去
   - git 说「没东西可提交」有两种措辞（nothing to commit / no changes added），
     少挡一种就会让每轮正常情况都误报 exit=1
